Telegram Side Panel - install (2 minutes)

1. Unzip this folder somewhere you will keep it (e.g. Documents).
2. In Chrome open: chrome://extensions
3. Turn on "Developer mode" (top right).
4. Click "Load unpacked" and pick the telegram-sidepanel folder.
5. Pin the extension, click its icon -> Telegram opens in the side panel.
6. Log in with your phone (QR code or number) once.

Permissions: only web.telegram.org + side panel + header rule for that site.
No other websites, no servers, no tracking. All code is 5 small files.
